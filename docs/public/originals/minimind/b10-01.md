# 29 · 归一化：LayerNorm、RMSNorm 与 Pre-Norm

<!-- LECTURE-CONTENT-START -->

在 Transformer 中，我们前面已经讨论过一个非常重要的问题：

```math
Attention(Q,K,V)
=
softmax\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
```

其中之所以要除以：

```math
\sqrt{d_k}
```

本质上是为了控制 Attention Score 的数值尺度。

因为如果 \(Q\)、\(K\) 每个维度的方差大约为 1，那么：

```math
Var(Q\cdot K)\approx d_k
```

于是：

```math
Std(Q\cdot K)\approx\sqrt{d_k}
```

所以需要除以：

```math
\sqrt{d_k}
```

把数值重新拉回一个稳定的尺度。

但这里又会产生一个新的问题：

> 我们为什么敢假设进入 Attention 的向量数值尺度是比较稳定的？

实际上，如果什么都不做，随着网络越来越深，神经网络内部的数值尺度可能不断变化。

这就引出了：

```text
Normalization
```

---

## 1. 深层网络首先面临的问题：数值尺度会不断漂移

假设某一层的 hidden state 是：

```math
x=[x_1,x_2,\dots,x_d]
```

开始时可能是：

```text
[-0.8, 0.3, 1.1, -0.4]
```

但是经过：

```text
Linear
↓
Attention
↓
Residual
↓
MLP
↓
Residual
↓
下一层
↓
下一层
...
```

以后，数值可能逐渐变成：

```text
[-8, 3, 11, -4]
```

甚至：

```text
[-80, 30, 110, -40]
```

也可能反过来变得越来越小：

```text
[-0.00008, 0.00003, 0.00011, -0.00004]
```

这就意味着：

```text
不同层之间的 activation 数值尺度可能不稳定
```

一旦数值尺度发生剧烈变化，就可能影响：

```text
Attention Score
↓
Softmax
↓
梯度传播
↓
训练稳定性
```

例如：

```text
hidden state 很大
        ↓
Q、K 很大
        ↓
Q·K 更大
        ↓
softmax 输入很大
        ↓
softmax 极其尖锐
```

因此，深层神经网络需要某种机制不断控制内部表示的数值尺度。

即：如果某一层 hidden state 的典型数值从 1 左右逐渐放大到 10、100，或者缩小到 0.001，那么后面由它生成的 Q、K、V、Attention score 和 MLP 输出都会跟着改变数量级。LayerNorm/RMSNorm 的作用，**就是尽量把每个 Block 的 hidden state 拉回到相近的尺度（1左右），** 让后续计算始终在比较稳定的数值范围里进行。

---

## 2. 一个最自然的想法：把数据标准化

假设：

```math
x=[2,4,6,8]
```

首先计算均值：

```math
\mu
=
\frac{2+4+6+8}{4}
=
5
```

然后计算方差：

```math
\sigma^2
=
\frac{
(2-5)^2+
(4-5)^2+
(6-5)^2+
(8-5)^2
}{4}
```

得到：

```math
\sigma^2=5
```

标准差：

```math
\sigma=\sqrt5
```

然后进行标准化：

```math
\hat{x_i}
=
\frac{x_i-\mu}
{\sqrt{\sigma^2+\epsilon}}
```

这就是 LayerNorm 最核心的思想。

---

## 3. LayerNorm 到底做了什么？

LayerNorm 可以简单理解成两步：

```text
第一步：重新居中
第二步：重新缩放
```

也就是：

```math
x_i
\rightarrow
x_i-\mu
\rightarrow
\frac{x_i-\mu}{\sigma}
```

完整公式：

```math
LayerNorm(x)
=
\frac{x-\mu}
{\sqrt{\sigma^2+\epsilon}}
\odot\gamma+\beta
```

其中：

```math
\mu
=
\frac{1}{d}
\sum_{i=1}^{d}x_i
```

```math
\sigma^2
=
\frac{1}{d}
\sum_{i=1}^{d}(x_i-\mu)^2
```

---

## 4. LayerNorm 第一步：减去均值

假设：

```math
x=[2,4,6,8]
```

均值：

```math
\mu=5
```

减去均值：

```math
x-\mu
=
[-3,-1,1,3]
```

这样以后：

```text
原来：

2  4  6  8

整体中心在 5 附近
```

变成：

```text
-3  -1  1  3

整体中心移动到 0
```

因此：

```math
Mean(x-\mu)=0
```

这叫：

```text
re-centering
重新居中
```

---

## 5. LayerNorm 第二步：除以标准差

现在：

```math
[-3,-1,1,3]
```

它虽然已经围绕 0，但整体尺度可能仍然比较大。

于是再除以标准差：

```math
\frac{x-\mu}{\sigma}
```

例如最终可能得到：

```math
[-1.34,-0.45,0.45,1.34]
```

此时：

```math
Mean\approx0
```

同时：

```math
Var\approx1
```

因此 LayerNorm 实际做的是：

```text
原始向量
   ↓
减去均值
   ↓
均值 ≈ 0
   ↓
除以标准差
   ↓
方差 ≈ 1
```

---

## 6. 为什么标准化后还需要 \(\gamma\) 和 \(\beta\)？

如果 LayerNorm 永远强行要求：

```math
Mean=0
```

以及：

```math
Var=1
```

可能会限制模型表达能力。

所以 LayerNorm 最后还会加入两个可学习参数：

```math
\gamma
```

和：

```math
\beta
```

最终：

```math
y
=
\gamma
\frac{x-\mu}
{\sqrt{\sigma^2+\epsilon}}
+
\beta
```

其中：

```text
γ：重新控制尺度
β：重新控制位置
```

可以理解成：

> 先把数据拉回一个稳定状态，然后让神经网络自己学习“真正需要的尺度和偏移”。

---

## 7. LayerNorm 为什么对 Transformer 很重要？

Transformer 中一个 token 的 hidden state 可能是：

```math
x\in\mathbb R^{4096}
```

它会不断经过：

```text
Attention
↓
Residual
↓
MLP
↓
Residual
↓
下一层
```

如果没有归一化，每层的数值尺度可能逐渐漂移。

LayerNorm 相当于不断告诉网络：

```text
不要让数值越来越大

也不要越来越小

尽量保持在稳定范围内
```

因此它可以：

```text
控制 activation 数值范围
↓
改善训练稳定性
↓
帮助深层网络训练
```

---

## 8. 但是 LayerNorm 又引出了一个问题

LayerNorm 同时做了：

```text
1. 减均值
2. 除标准差
```

也就是说：

```text
重新居中
+
重新缩放
```

于是有人提出一个问题：

> 对 Transformer 来说，我们真正最需要的，是不是其实只是“控制尺度”？

换句话说：

```text
减均值真的必须吗？
```

如果真正危险的是：

```text
1
→
10
→
100
→
1000
```

这种 activation 尺度不断膨胀，

那么也许只要控制：

```text
向量整体大小
```

就足够了。

这就是 RMSNorm 的出发点。

---

## 9. RMS 是什么？

RMS 的全称：

```text
Root Mean Square
```

中文：

```text
均方根
```

对于向量：

```math
x=[x_1,x_2,\dots,x_d]
```

RMS 定义为：

```math
RMS(x)
=
\sqrt{
\frac{1}{d}
\sum_{i=1}^{d}x_i^2
}
```

步骤很简单：

```text
每个数平方
↓
求平均
↓
开平方
```

---

## 10. RMSNorm 怎么做？

RMSNorm 直接使用：

```math
RMSNorm(x)
=
\frac{x}
{\sqrt{
\frac{1}{d}\sum_{i=1}^{d}x_i^2+\epsilon
}}
\odot\gamma
```

注意它与 LayerNorm 最大的区别：

### 10.1 LayerNorm

```math
\frac{x-\mu}
{\sqrt{
\frac{1}{d}\sum_i(x_i-\mu)^2+\epsilon
}}
```

### 10.2 RMSNorm

```math
\frac{x}
{\sqrt{
\frac{1}{d}\sum_i x_i^2+\epsilon
}}
```

RMSNorm 没有：

```math
x-\mu
```

这一步。

---

## 11. LayerNorm 和 RMSNorm 的核心区别

可以直接记成：

```text
LayerNorm：

重新居中
+
重新缩放
```

即：

```text
减均值
+
控制尺度
```

而：

```text
RMSNorm：

只重新缩放
```

也就是：

```text
不减均值
只控制尺度
```

因此：

```math
\boxed{
RMSNorm
\approx
去掉“减均值”的 LayerNorm
}
```

当然，两者并不严格等价。

---

## 12. 一个具体例子

假设：

```math
x=[1,2,3,4]
```

---

### 12.1 LayerNorm

均值：

```math
\mu
=
\frac{1+2+3+4}{4}
=
2.5
```

减均值：

```math
[-1.5,-0.5,0.5,1.5]
```

再除以标准差，得到大约：

```math
[-1.34,-0.45,0.45,1.34]
```

因此：

```text
均值 ≈ 0
方差 ≈ 1
```

---

### 12.2 RMSNorm

首先计算：

```math
RMS
=
\sqrt{
\frac{
1^2+2^2+3^2+4^2
}{4}
}
```

即：

```math
RMS
=
\sqrt{\frac{30}{4}}
```

约为：

```math
RMS\approx2.739
```

然后：

```math
x'
=
\frac{[1,2,3,4]}{2.739}
```

得到：

```math
x'
\approx
[0.365,0.730,1.095,1.461]
```

注意：

```text
它的均值并不是 0
```

但：

```math
\frac{
0.365^2+
0.730^2+
1.095^2+
1.461^2
}{4}
\approx1
```

所以：

```math
RMS(x')\approx1
```

RMSNorm 达到了自己的目标：

> 控制向量整体数值尺度，而不强制均值变成 0。

---

## 13. RMSNorm 为什么有效？

很多深层网络真正危险的问题往往是：

```text
activation 的绝对尺度越来越大
```

例如：

```text
第 1 层：

[1, 2, 3]

第 10 层：

[10, 20, 30]

第 30 层：

[1000, 2000, 3000]
```

这种尺度漂移可能导致：

```text
Q、K 变大
↓
QK^T 变大
↓
softmax 过于尖锐
↓
训练不稳定
```

而 RMSNorm 可以不断把：

```text
向量整体尺度
```

拉回一个比较稳定的范围。

因此很多 Transformer 场景中：

```text
控制尺度
```

往往已经足够重要。

---
### 13.1 具体看一下 RMSNorm 是怎么把不同尺度拉回来的

假设不同层的 activation 分别是：

```text
第 1 层：

[1, 2, 3]

第 10 层：

[10, 20, 30]

第 30 层：

[1000, 2000, 3000]
```

这三个向量其实方向完全相同，只是整体尺度越来越大：

```text
[10, 20, 30]
=
10 × [1, 2, 3]

[1000, 2000, 3000]
=
1000 × [1, 2, 3]
```

RMSNorm 会对每个向量先计算自己的 RMS：

```math
RMS(x)
=
\sqrt{
\frac{1}{d}
\sum_{i=1}^{d}x_i^2
}
```

---

#### 13.1.1 第 1 层

```math
x=[1,2,3]
```

RMS 为：

```math
RMS(x)
=
\sqrt{
\frac{1^2+2^2+3^2}{3}
}
```

```math
=
\sqrt{
\frac{14}{3}
}
\approx 2.160
```

所以归一化之后：

```math
\hat{x}
=
\left[
\frac{1}{2.160},
\frac{2}{2.160},
\frac{3}{2.160}
\right]
```

得到：

```math
\hat{x}
\approx
[0.463,\ 0.926,\ 1.389]
```

---

#### 13.1.2 第 10 层

```math
x=[10,20,30]
```

RMS 为：

```math
RMS(x)
=
\sqrt{
\frac{10^2+20^2+30^2}{3}
}
```

```math
=
\sqrt{
\frac{1400}{3}
}
\approx 21.602
```

所以：

```math
\hat{x}
=
\left[
\frac{10}{21.602},
\frac{20}{21.602},
\frac{30}{21.602}
\right]
```

得到：

```math
\hat{x}
\approx
[0.463,\ 0.926,\ 1.389]
```

---

#### 13.1.3 第 30 层

```math
x=[1000,2000,3000]
```

RMS 为：

```math
RMS(x)
=
\sqrt{
\frac{1000^2+2000^2+3000^2}{3}
}
```

```math
=
\sqrt{
\frac{14,000,000}{3}
}
\approx 2160.247
```

所以：

```math
\hat{x}
=
\left[
\frac{1000}{2160.247},
\frac{2000}{2160.247},
\frac{3000}{2160.247}
\right]
```

得到：

```math
\hat{x}
\approx
[0.463,\ 0.926,\ 1.389]
```

---

于是原来的：

```text
第 1 层：
[1, 2, 3]

第 10 层：
[10, 20, 30]

第 30 层：
[1000, 2000, 3000]
```

经过 RMSNorm 后都会变成：

```text
[0.463, 0.926, 1.389]
```

也就是说：

```text
[1, 2, 3]
      ↓
   RMSNorm
      ↓
[0.463, 0.926, 1.389]


[10, 20, 30]
      ↓
   RMSNorm
      ↓
[0.463, 0.926, 1.389]


[1000, 2000, 3000]
      ↓
   RMSNorm
      ↓
[0.463, 0.926, 1.389]
```

所以 RMSNorm 做的事情可以概括成：

```text
整体放大 10 倍
→ RMS 也放大 10 倍
→ 一除，10 倍被抵消

整体放大 1000 倍
→ RMS 也放大 1000 倍
→ 一除，1000 倍也被抵消
```

数学上，如果：

```math
x'=cx
```

那么：

```math
RMS(x')
=
RMS(cx)
=
|c|RMS(x)
```

因此当 `c > 0` 时：

```math
\frac{cx}{RMS(cx)}
=
\frac{cx}{cRMS(x)}
=
\frac{x}{RMS(x)}
```

所以：

```text
RMSNorm 并不是把每个数压到 0~1。

它真正做的是：

消除向量整体的尺度变化，
同时保留各维度之间原本的相对比例。
```

这就是为什么即使深层网络中的 activation 从：

```text
[1, 2, 3]
```

一路漂移成：

```text
[1000, 2000, 3000]
```

RMSNorm 依然可以在进入后续 Attention 或 MLP 之前，把它们重新拉回到近似一致的数值尺度。


---

## 14. 为什么现在很多 LLM 使用 RMSNorm？

可以把原因概括成：

```text
LayerNorm：

控制中心
+
控制尺度
```

而：

```text
RMSNorm：

只控制尺度
```

RMSNorm 不需要显式执行：

```text
求均值
↓
每个元素减去均值
```

所以：

```text
实现更简单
计算路径更简单
同时在很多 Transformer / LLM 中效果很好
```

因此很多现代大语言模型会使用：

```text
RMSNorm
```

来替代经典 LayerNorm。

但应该注意：

> 不是因为 LayerNorm “错了”，而是 RMSNorm 发现，对于很多 Transformer 场景，只做尺度归一化就已经足够有效。

---

## 15. 到这里还有一个问题：Norm 应该放在哪里？

假设我们已经决定：

```text
需要 Norm
```

那么马上会出现另一个问题：

> Norm 应该放在 Attention / MLP 前面，还是后面？

这就产生了：

```text
Post-Norm
```

和：

```text
Pre-Norm
```

---

## 16. 先从最简单的残差连接开始

暂时不要管 Transformer。

假设输入：

```math
x
```

有一个神经网络模块：

```math
F(x)
```

这里的 \(F\) 可以代表：

```text
Attention
```

也可以代表：

```text
MLP
```

最简单的残差结构：

```math
y=x+F(x)
```

结构：

```text
x ───────────────────┐
                     +
x → F(x) ─────────────┘
                     ↓
                     y
```

这里存在两条路径：

```text
第一条：

x ───────────────→ y
```

这是：

```text
Residual / Skip Connection
```

另一条：

```text
x
↓
F(x)
↓
y
```

---

## 17. 为什么 Residual Connection 很重要？

因为即使：

```math
F(x)
```

非常复杂，

至少还有：

```math
x
```

可以直接传过去。

所以：

```math
y=x+F(x)
```

意味着：

> 网络不需要每一层都重新构造整个表示，只需要在原有 \(x\) 的基础上学习一个增量。

可以理解成：

```text
新表示
=
旧表示
+
这一层学习到的修改
```

---

## 18. Post-Norm 是什么？

原始 Transformer 使用的是典型的 Post-Norm。

公式：

```math
\boxed{
y=Norm(x+F(x))
}
```

执行顺序：

```text
x
↓
F(x)
↓
和原来的 x 相加
↓
Norm
↓
y
```

所以叫：

```text
Post-Norm
```

因为 Norm 在 residual addition 之后。

结构：

```text
x ──────────────────┐
                    +
x → F(x) ────────────┘
                    ↓
                   Norm
                    ↓
                    y
```

---

## 19. Post-Norm 的一个具体例子

假设：

```math
x=[1,2,3]
```

Attention 输出：

```math
F(x)=[0.1,0.2,0.3]
```

首先做 Residual：

```math
x+F(x)
```

得到：

```math
[1.1,2.2,3.3]
```

然后再做：

```math
Norm([1.1,2.2,3.3])
```

假设得到：

```math
[-1.22,0,1.22]
```

注意：

虽然原来的：

```math
x=[1,2,3]
```

通过 residual 被加进去了，

但是之后又整体经过了一次：

```text
Norm
```

所以最终已经不再保留原始：

```math
[1,2,3]
```

的数值形式。

---

## 20. Post-Norm 的关键特点

Post-Norm：

```math
y=Norm(x+F(x))
```

虽然存在：

```text
Residual Connection
```

但是：

```text
x
```

并不是完全直接地传递到下一层。

因为：

```text
x
↓
+
↓
Norm
↓
下一层
```

也就是说：

> residual path 最终仍然必须经过 Norm。

---

## 21. Pre-Norm 是什么？

后来越来越多 Transformer 使用 Pre-Norm。

公式：

```math
\boxed{
y=x+F(Norm(x))
}
```

执行顺序：

```text
x
↓
Norm
↓
F
↓
和原始 x 相加
↓
y
```

结构：

```text
x ─────────────────────────┐
                           +
x → Norm → F ───────────────┘
                           ↓
                           y
```

这时候最大的区别出现了：

> 原始 \(x\) 有一条完全不经过 Norm 的直通路径。

即：

```text
x
──────────────────────────→ y
```

---

## 22. 用同样的数字看 Pre-Norm

还是：

```math
x=[1,2,3]
```

先：

```math
Norm(x)
```

假设得到：

```math
[-1.22,0,1.22]
```

再经过：

```math
F
```

假设：

```math
F(Norm(x))
=
[0.1,0.2,0.3]
```

最后：

```math
y
=
x+
F(Norm(x))
```

于是：

```math
y
=
[1,2,3]
+
[0.1,0.2,0.3]
```

得到：

```math
\boxed{
[1.1,2.2,3.3]
}
```

这里原始：

```math
[1,2,3]
```

完整保留在 residual path 中。

---

## 23. Pre-Norm 和 Post-Norm 最核心的区别

直接看公式。

### 23.1 Post-Norm

```math
\boxed{
y=Norm(x+F(x))
}
```

结构：

```text
x ───────────────┐
                 +
x → F ────────────┘
                 ↓
                Norm
                 ↓
                 y
```

### 23.2 Pre-Norm

```math
\boxed{
y=x+F(Norm(x))
}
```

结构：

```text
x ───────────────────┐
                     +
x → Norm → F ─────────┘
                     ↓
                     y
```

一句话：

```text
Post-Norm：
Norm 在 residual 相加之后

Pre-Norm：
Norm 在 F 之前
```

---

## 24. 为什么 Pre-Norm 更有利于梯度传播？

这是 Pre-Norm 非常重要的原因。

对于：

```math
y=x+F(Norm(x))
```

对 \(x\) 求导：

```math
\frac{\partial y}{\partial x}
=
1+
\frac{\partial F(Norm(x))}
{\partial x}
```

这里有一个非常重要的：

```math
\boxed{1}
```

因为：

```math
\frac{\partial x}{\partial x}=1
```

也就是说，即使：

```math
\frac{\partial F}{\partial x}
```

很小，

梯度仍然有一条：

```text
直接通过 x 的路径
```

可以传播。

---

## 25. Pre-Norm 的梯度通道

可以画成：

```text
Forward：

x ────────────────────────┐
                          +
x → Norm → F ──────────────┘
                          ↓
                          y
```

反向传播时：

```text
gradient
    ↓
    ├────────────────────→ x
    │
    └→ F → Norm ─────────→ x
```

因此存在一条：

```text
gradient
↓
直接回到 x
```

的路径。

这就是：

```text
Identity Gradient Path
```

---

## 26. Post-Norm 的梯度有什么不同？

Post-Norm：

```math
y=Norm(x+F(x))
```

令：

```math
z=x+F(x)
```

那么：

```math
y=Norm(z)
```

所以：

```math
\frac{\partial y}{\partial x}
=
\frac{\partial Norm(z)}
{\partial z}
\left(
1+
\frac{\partial F(x)}
{\partial x}
\right)
```

注意：

虽然 residual 中也有：

```math
1
```

但整个东西外面还乘着：

```math
\frac{\partial Norm}
{\partial z}
```

因此：

> 梯度无法完全绕过 Norm。

结构上：

```text
gradient
   ↓
  Norm
   ↓
   +
  / \
 x   F
```

所有梯度首先都要通过：

```text
Norm
```

---

## 27. 为什么网络越深，这个区别越重要？

假设网络只有：

```text
2 层
```

差异可能没那么明显。

但如果有：

```text
32 层
64 层
80 层
100 层
```

Post-Norm 的梯度可能需要连续经过：

```text
Norm
↓
Norm
↓
Norm
↓
Norm
↓
...
```

而 Pre-Norm 始终保留：

```text
x
↓
x + ...
↓
x + ...
↓
x + ...
↓
...
```

这样一条 identity path。

因此在很深的 Transformer 中：

```math
\boxed{
Pre\text{-}Norm
}
```

通常更容易获得稳定的优化。

---

## 28. 一个 Transformer Block 其实有两个 Norm

因为一个典型 Transformer Block 包含两个主要子模块：

```text
Attention

MLP
```

所以 Pre-Norm 通常不是只做一次。

第一个子层：

```math
x_1
=
x+
Attention(Norm(x))
```

第二个子层：

```math
x_2
=
x_1+
MLP(Norm(x_1))
```

结构：

```text
             ┌───────────────────────┐
             │                       │
x ───────────┼───────────────────────+
             │                       ↑
             ↓                       │
           Norm                      │
             ↓                       │
         Attention ──────────────────┘
             ↓
            x₁
             │
             ├───────────────────────+
             │                       ↑
             ↓                       │
           Norm                      │
             ↓                       │
            MLP ─────────────────────┘
             ↓
            x₂
```

---

## 29. Post-Norm Transformer Block

Post-Norm 对应：

```math
x_1
=
Norm(x+Attention(x))
```

然后：

```math
x_2
=
Norm(x_1+MLP(x_1))
```

结构：

```text
x ──────────────────┐
                    +
x → Attention ───────┘
                    ↓
                  Norm
                    ↓
                   x₁
                    │
                    ├───────────────┐
                    │               +
                    └→ MLP ─────────┘
                                    ↓
                                  Norm
                                    ↓
                                   x₂
```

## 30. 现代 LLM 为什么经常是 Pre-Norm + RMSNorm？

现在可以把前面所有内容串起来。

RMSNorm 解决：

```text
输入 Attention / MLP 的数值尺度
```

Pre-Norm 解决：

```text
Residual / Gradient 直通路径
```

所以现代结构经常写成：

```math
x_1
=
x+
Attention(RMSNorm(x))
```

然后：

```math
x_2
=
x_1+
MLP(RMSNorm(x_1))
```

即：

```text
RMSNorm
↓
控制进入子层的尺度

Pre-Norm
↓
不破坏 residual identity path
```

两者解决的是不同的问题。

---

## 31. 现代 Transformer Block 的直观结构

典型形式：

```text
             ┌─────────────────────────┐
             │                         │
x ───────────┼─────────────────────────+
             │                         ↑
             ↓                         │
          RMSNorm                      │
             ↓                         │
         Attention ────────────────────┘
             ↓
             x₁
             │
             ├─────────────────────────+
             │                         ↑
             ↓                         │
          RMSNorm                      │
             ↓                         │
            MLP ───────────────────────┘
             ↓
             x₂
```

所以一层 Transformer 可以理解为：

```text
第一步：

先把 x 的尺度控制好
↓
Attention
↓
把 Attention 产生的“修改量”加回原来的 x


第二步：

再把新的 x₁ 尺度控制好
↓
MLP
↓
把 MLP 产生的“修改量”加回 x₁
```

因此每个 Block 更像是在：

```text
原来的表示
+
Attention 学到的一点修改
+
MLP 学到的一点修改
```

而不是每一层都完全重新生成 hidden state。

核心区别是：

> **\(\sqrt{d_k}\) 只解决“点积因为维度变大而自然变大”的问题；LayerNorm/RMSNorm 解决的是“进入 Attention/MLP 的 hidden state 自身尺度会随层数和训练过程漂移”的问题。**

---

## 32. Attention 已经除以 \(\sqrt{d_k}\)，为什么还需要 LayerNorm？

在 Attention 中，我们已经有：

```math
Attention(Q,K,V)
=
softmax\left(
\frac{QK^T}{\sqrt{d_k}}
\right)V
```

其中：

```math
\frac{1}{\sqrt{d_k}}
```

就是为了控制 \(QK^T\) 的数值尺度。

那么一个很自然的问题就是：

> Attention 已经做了数值缩放，为什么 Transformer 里还需要 LayerNorm 或 RMSNorm？

答案是：

```text
÷ √d_k
```

和：

```text
LayerNorm / RMSNorm
```

解决的是**两个不同层次的问题**。

---

## 33. 先回顾为什么 Attention 要除以 \(\sqrt{d_k}\)

假设：

```math
Q=(q_1,q_2,\dots,q_{d_k})
```

```math
K=(k_1,k_2,\dots,k_{d_k})
```

那么：

```math
Q\cdot K
=
q_1k_1+
q_2k_2+
\cdots+
q_{d_k}k_{d_k}
```

如果理想化地假设每一维：

```math
E(q_i)\approx0,\qquad Var(q_i)\approx1
```

```math
E(k_i)\approx0,\qquad Var(k_i)\approx1
```

那么：

```math
Var(Q\cdot K)
\approx d_k
```

所以：

```math
Std(Q\cdot K)
\approx\sqrt{d_k}
```

于是我们除以：

```math
\sqrt{d_k}
```

得到：

```math
Std\left(
\frac{Q\cdot K}{\sqrt{d_k}}
\right)
\approx1
```

因此：

> **除以 \(\sqrt{d_k}\) 解决的是：点积项太多以后，Attention Score 会随着维度 \(d_k\) 增大而自然变大。**

---

## 34. 但是这里偷偷做了一个假设

刚才整个推导有一个非常重要的前提：

```math
Var(q_i)\approx1
```

以及：

```math
Var(k_i)\approx1
```

问题是：

> 神经网络训练过程中，谁保证 \(Q\) 和 \(K\) 的尺度一直这么稳定？

实际上，并没有天然保证。

例如某一层输入 hidden state：

```math
x
```

通过线性变换：

```math
Q=xW_Q
```

```math
K=xW_K
```

如果：

```math
x
```

本身越来越大，

那么：

```math
Q
```

和：

```math
K
```

也可能一起变大。

---

## 35. 一个具体例子

假设理想情况下：

```text
Q 每个元素尺度 ≈ 1
K 每个元素尺度 ≈ 1
```

那么：

```math
QK^T
```

的标准差大约是：

```math
\sqrt{d_k}
```

除以：

```math
\sqrt{d_k}
```

正好变成：

```text
尺度 ≈ 1
```

很好。

---

但是假设网络训练到某一层以后：

```text
Q 每个元素尺度 ≈ 10
K 每个元素尺度 ≈ 10
```

那么每一项：

```math
q_i k_i
```

的尺度大约会变成：

```math
10\times10=100
```

于是整个点积的标准差大约不再是：

```math
\sqrt{d_k}
```

而是：

```math
100\sqrt{d_k}
```

现在再除：

```math
\sqrt{d_k}
```

得到：

```math
\frac{
100\sqrt{d_k}
}{
\sqrt{d_k}
}
=
100
```

Attention Score 还是非常大。

例如第 1 个 Block 里的 Attention score 大多在 \(-2\sim2\) 附近，如果传到第 20 个 Block 时变成了 \(-50\sim50\)，softmax 就会变得特别尖锐，训练行为也会变得很不一样。LayerNorm/RMSNorm 的作用之一，**就是尽量让每个 Block 送进去的表示都保持在相近的数值尺度上，** 让各层的 Attention 不至于一层比一层“数值爆掉”。

---

## 36. 这就是 \(\sqrt{d_k}\) 的局限

```math
\frac{QK^T}{\sqrt{d_k}}
```

只能消除：

```text
“因为维度 d_k 很大，所以很多项相加造成的尺度膨胀”
```

它不能解决：

```text
“Q 和 K 自己本来就已经很大”
```

所以可以记成：

```text
÷ √d_k：

解决“维度效应”
```

而：

```text
LayerNorm / RMSNorm：

解决“输入本身尺度漂移”
```

---

## 37. 用公式看得更清楚

不要假设：

```math
Var(q_i)=1
```

而是假设：

```math
Var(q_i)=\sigma_Q^2
```

```math
Var(k_i)=\sigma_K^2
```

在近似独立的情况下：

```math
Var(q_i k_i)
\approx
\sigma_Q^2\sigma_K^2
```

所以：

```math
Var(Q\cdot K)
\approx
d_k\sigma_Q^2\sigma_K^2
```

因此：

```math
Std(Q\cdot K)
\approx
\sqrt{d_k}\sigma_Q\sigma_K
```

除以：

```math
\sqrt{d_k}
```

之后：

```math
Std\left(
\frac{Q\cdot K}{\sqrt{d_k}}
\right)
\approx
\sigma_Q\sigma_K
```

注意：

```math
\boxed{
\sqrt{d_k}
}
```

被消掉了，

但是：

```math
\boxed{
\sigma_Q\sigma_K
}
```

还在。

这就是最关键的一点。

---

## 38. 举个非常直观的数字例子

假设：

```math
d_k=64
```

所以：

```math
\sqrt{d_k}=8
```

### 38.1 情况 A：Q、K 尺度正常

假设：

```math
\sigma_Q=1
```

```math
\sigma_K=1
```

那么：

```math
Std(Q\cdot K)
\approx
8\times1\times1
=
8
```

除以：

```math
8
```

之后：

```math
Std\approx1
```

很好。

---

### 38.2 情况 B：Q、K 都放大 10 倍

现在：

```math
\sigma_Q=10
```

```math
\sigma_K=10
```

那么：

```math
Std(Q\cdot K)
\approx
8\times10\times10
```

即：

```math
Std(Q\cdot K)\approx800
```

即使除以：

```math
\sqrt{64}=8
```

仍然得到：

```math
800/8=100
```

也就是：

```math
Std\approx100
```

依然非常大。

所以：

```text
÷ √d_k
```

并不能拯救一个本身尺度已经失控的 \(Q\) 和 \(K\)。

---

## 39. LayerNorm / RMSNorm 在这里负责什么？

假设当前 hidden state：

```math
x
```

的数值越来越大：

```text
第 1 层：

[-1, 0.5, 1.2, ...]

第 10 层：

[-10, 5, 12, ...]

第 30 层：

[-100, 50, 120, ...]
```

那么：

```math
Q=xW_Q
```

```math
K=xW_K
```

也可能越来越大。

于是 Attention：

```text
x 尺度变大
   ↓
Q、K 变大
   ↓
QK^T 变大
   ↓
即使 ÷ √d_k
仍然可能很大
   ↓
softmax 过于尖锐
```

所以在进入 Attention 之前做：

```text
LayerNorm / RMSNorm
```

就可以先控制：

```math
x
```

的尺度。

---

## 40. Pre-Norm 下就特别直观

现代 LLM 经常写：

```math
x'
=
x+
Attention(RMSNorm(x))
```

注意 Attention 真正接收到的不是：

```math
x
```

而是：

```math
RMSNorm(x)
```

先：

```text
x
↓
RMSNorm
↓
把输入尺度控制稳定
```

然后：

```text
稳定的 hidden state
↓
W_Q、W_K、W_V
↓
Q、K、V
```

再：

```text
Q、K
↓
QK^T
↓
÷ √d_k
↓
控制“点积维度效应”
```

所以实际上是两层保护。

---

## 41. 两种机制可以理解成“各管一段”

完整过程：

```text
hidden state x
      ↓
   RMSNorm
      ↓
控制 x 本身的尺度
      ↓
 ┌────┼────┐
 ↓    ↓    ↓
 Q    K    V
 ↓    ↓
 └─ QK^T ──┘
      ↓
   ÷ √d_k
      ↓
控制点积因为维度增加产生的尺度膨胀
      ↓
   softmax
      ↓
Attention Output
```

所以：

```text
RMSNorm / LayerNorm
```

处理的是：

```text
进入 Attention 之前
hidden state 本身是否稳定
```

而：

```math
1/\sqrt{d_k}
```

处理的是：

```text
Attention 内部
Q 和 K 做 d_k 维点积以后产生的尺度增长
```

---

## 42. BatchNorm 与 RMSNorm 的区别

**标准 Transformer 里通常没有 BatchNorm。**

更准确地说：

原始 Transformer 用的是 LayerNorm
现在很多 LLM 用的是 RMSNorm
BatchNorm 在 Transformer 里不是主流配置

原因主要有三个：

Transformer 的序列长度和 batch size 经常变化
BatchNorm 依赖 batch 内统计量，不太稳定。
一个 token 不应该被同 batch 里别的样本影响

BatchNorm 会跨样本算均值/方差，而 LayerNorm、RMSNorm 是对每个 token 自己的 hidden state 做归一化。

训练和推理一致性更好

LayerNorm / RMSNorm 不需要 running_mean、running_var，训练和推理行为基本一致。

BatchNorm 和之前学习的 **RMSNorm** 都属于归一化（Normalization）方法，但它们最核心的区别是：

> **BatchNorm：不同样本之间一起计算统计量。**
> **RMSNorm：每个样本 / Token 自己内部计算统计量。**

这也是为什么：

* **BatchNorm** 在 CNN、传统 MLP 中非常常见；
* **LayerNorm / RMSNorm** 在 Transformer、LLM 中更加常见。

---

## 43. BatchNorm 是什么？

BatchNorm 全称：

```text
Batch Normalization
```

即：

> **批归一化**

它的核心思想是：

```text
取一个 Mini-batch
        ↓
统计某个特征在这一批样本中的均值和方差
        ↓
把这个特征归一化
        ↓
再进行缩放和平移
```

---

## 44. 一个最简单的 BatchNorm 例子

假设某个神经元对于一个 Batch 中的 4 个样本产生：

```text
[2, 4, 6, 8]
```

也就是：

$$
x=[2,4,6,8]
$$

---

### 44.1 第一步：计算 Batch 均值

$$
\mu_B
=
\frac{2+4+6+8}{4}
=
5
$$

---

### 44.2 第二步：计算 Batch 方差

$$
\sigma_B^2
=
\frac{
(2-5)^2+
(4-5)^2+
(6-5)^2+
(8-5)^2
}{4}
$$

因此：

$$
\sigma_B^2=5
$$

---

### 44.3 第三步：标准化

BatchNorm 使用：

$$
\hat{x}_i
=
\frac{x_i-\mu_B}
{\sqrt{\sigma_B^2+\epsilon}}
$$

代入：

$$
[2,4,6,8]
$$

大约得到：

$$
[-1.34,-0.45,0.45,1.34]
$$

这时候整个 Batch 的数据：

```text
均值 ≈ 0
方差 ≈ 1
```

---

## 45. 为什么还需要 γ 和 β？

如果永远强制网络的输出：

```text
均值 = 0
方差 = 1
```

可能会限制网络的表达能力。

因此 BatchNorm 又加入两个可学习参数：

$$
\gamma
$$

和：

$$
\beta
$$

最终：

$$
y_i
=
\gamma\hat{x}_i+\beta
$$

所以完整公式为：

$$
\boxed{
y_i
=
\gamma
\frac{x_i-\mu_B}
{\sqrt{\sigma_B^2+\epsilon}}
+
\beta
}
$$

其中：

* \(\gamma\)：控制缩放；
* \(\beta\)：控制平移。

---

## 46. 为什么叫 BatchNorm？

关键就在：

```text
Batch
```

假设输入矩阵：

$$
X=
\begin{bmatrix}
1&2&3\\
4&5&6\\
7&8&9
\end{bmatrix}
$$

可以理解为：

```text
           feature1   feature2   feature3

sample1       1          2          3
sample2       4          5          6
sample3       7          8          9
```

BatchNorm 会：

> **沿着 Batch 方向，对每一个 Feature 分别进行归一化。**

---

例如第一个 Feature：

$$
[1,4,7]
$$

均值：

$$
\mu_1=4
$$

第二个 Feature：

$$
[2,5,8]
$$

均值：

$$
\mu_2=5
$$

第三个 Feature：

$$
[3,6,9]
$$

均值：

$$
\mu_3=6
$$

所以 BatchNorm 是：

```text
        ↓        ↓        ↓
      feature1 feature2 feature3

样本1    1        2        3
样本2    4        5        6
样本3    7        8        9
```

即：

> 同一个特征，跨多个样本统计。

---

## 47. RMSNorm 是什么？

RMSNorm 全称：

```text
Root Mean Square Normalization
```

即：

> 均方根归一化。

和 BatchNorm 最大的不同是：

> RMSNorm 不需要看其他样本。

假设某个 Token 的 Hidden State：

$$
x=[1,2,3,4]
$$

RMSNorm 计算：

$$
RMS(x)
=
\sqrt{
\frac{
1^2+2^2+3^2+4^2
}{4}
+\epsilon
}
$$

因此：

$$
RMS(x)
=
\sqrt{\frac{30}{4}}
=
\sqrt{7.5}
\approx2.739
$$

然后：

$$
\hat{x}
=
\frac{x}{RMS(x)}
$$

得到：

$$
[0.365,\;0.730,\;1.095,\;1.460]
$$

最后乘一个可学习参数：

$$
y
=
\gamma\odot\hat{x}
$$

因此：

$$
\boxed{
RMSNorm(x)
=
\gamma\odot
\frac{x}
{
\sqrt{
\frac1d
\sum_{j=1}^{d}x_j^2
+\epsilon
}
}
}
$$

---

## 48. RMSNorm 一个非常重要的特点：不减均值

BatchNorm 中有：

$$
x-\mu
$$

LayerNorm 中也有：

$$
x-\mu
$$

但 RMSNorm：

$$
\boxed{
没有减均值
}
$$

它只控制：

> 整个向量的数值尺度。

所以：

```text
LayerNorm

减均值
   +
除标准差
```

而：

```text
RMSNorm

不减均值
   +
除 RMS
```

---

## 49. BatchNorm 和 RMSNorm 最核心的区别

假设：

$$
X\in\mathbb{R}^{B\times D}
$$

其中：

* \(B\)：Batch Size；
* \(D\)：特征维度。

例如：

$$
X\in\mathbb{R}^{32\times4096}
$$

---

### 49.1 BatchNorm

它会：

```text
第1维特征：
32个样本一起统计

第2维特征：
32个样本一起统计

...

第4096维特征：
32个样本一起统计
```

即：

$$
\boxed{
沿Batch维统计
}
$$

---

### 49.2 RMSNorm

对于第一个样本：

```text
它自己的4096维
↓
计算RMS
↓
归一化
```

第二个样本：

```text
它自己的4096维
↓
计算RMS
↓
归一化
```

彼此完全独立。

即：

$$
\boxed{
沿特征维统计
}
$$

---

## 50. 一个特别直观的图

假设：

$$
X=
\begin{bmatrix}
1&2&3\\
4&5&6\\
7&8&9
\end{bmatrix}
$$

---

### 50.1 BatchNorm：竖着算

```text
↓     ↓     ↓

1     2     3
4     5     6
7     8     9
```

例如：

```text
[1, 4, 7]
```

一起归一化。

---

### 50.2 RMSNorm：横着算

```text
1  2  3  →
4  5  6  →
7  8  9  →
```

例如：

```text
[1, 2, 3]
```

自己归一化。

---

## 51. BatchNorm 的一个特殊性质：一个样本受其他样本影响

假设当前某个值：

$$
x=5
$$

---

### 51.1 Batch A

```text
[4, 5, 6]
```

均值：

$$
\mu=5
$$

所以：

$$
5-5=0
$$

归一化以后接近：

$$
0
$$

---

### 51.2 Batch B

换一个 Batch：

```text
[5, 100, 200]
```

此时均值：

$$
\mu
=
\frac{5+100+200}{3}
\approx101.67
$$

虽然：

$$
x
$$

仍然是：

$$
5
$$

但归一化结果已经完全不同。

所以：

$$
\boxed{
BatchNorm中一个样本的结果
会受到同一个Batch中其他样本影响
}
$$

---

## 52. RMSNorm 不存在这个问题

假设当前 Token：

$$
x=[1,2,3,4]
$$

RMSNorm 只计算：

$$
RMS(x)
$$

至于 Batch 里面还有什么：

```text
样本A
样本B
样本C
样本D
```

都没有关系。

因此：

$$
\boxed{
RMSNorm不同样本之间互不影响
}
$$

---

## 53. BatchNorm 为什么有效？

神经网络训练过程中，每一层的输出分布可能不断发生变化。

例如：

```text
Epoch 1：

均值 ≈ 0
方差 ≈ 1
```

过一段时间：

```text
Epoch 10：

均值 ≈ 20
方差 ≈ 100
```

再过一段时间：

```text
Epoch 20：

均值 ≈ -30
方差 ≈ 500
```

后面的网络层就需要不断适应前面的数值变化。

BatchNorm 相当于不断做：

```text
某层输出
   ↓
数值尺度可能很乱
   ↓
BatchNorm
   ↓
重新拉回比较稳定的范围
```

因此训练通常：

* 更稳定；
* 可以使用更大的学习率；
* 更容易收敛。

---

## 54. BatchNorm 在 MLP 中放在哪里？

一种经典结构：

```text
Linear
  ↓
BatchNorm
  ↓
ReLU
```

也就是：

$$
x
$$

先经过：

$$
z=Wx+b
$$

然后：

$$
BN(z)
$$

再：

$$
ReLU
$$

完整流程：

```text
输入
 ↓
Linear
 ↓
BatchNorm
 ↓
ReLU
 ↓
Linear
 ↓
BatchNorm
 ↓
ReLU
 ↓
输出层
```

---

## 55. BatchNorm 在 CNN 中为什么特别常见？

经典 CNN 中经常看到：

```text
Conv
 ↓
BatchNorm
 ↓
ReLU
```

例如：

```python
nn.Conv2d(...)
nn.BatchNorm2d(...)
nn.ReLU()
```

原因是 CNN 的 Feature Channel 非常适合做 Batch 统计。

---

## 56. 为什么 Transformer 很少使用 BatchNorm？

Transformer 中的数据通常是：

$$
X
\in
\mathbb{R}^{B\times T\times D}
$$

例如：

$$
B=32
$$

$$
T=1024
$$

$$
D=4096
$$

分别表示：

```text
32个句子
每个句子1024个Token
每个Token 4096维
```

如果使用 BatchNorm：

> 某一个 Token 的归一化结果可能受到其他句子影响。

例如：

```text
句子1：
我 喜欢 人工 智能
```

其中：

```text
人工
```

这个 Token 的 Hidden State，理论上应该主要由：

```text
当前句子
当前上下文
```

决定。

但 BatchNorm 可能让它受到：

```text
Batch里面另外31个句子
```

的影响。

这对 Transformer 并不是非常理想。

---

## 57. RMSNorm 为什么更适合 Transformer？

假设 Transformer 某个 Token：

$$
x
\in
\mathbb{R}^{4096}
$$

RMSNorm：

```text
当前Token的4096维
        ↓
     计算RMS
        ↓
      归一化
```

完全不需要其他 Token 或其他样本。

因此：

```text
Token A
自己处理

Token B
自己处理

Token C
自己处理
```

这非常符合 Transformer 的计算方式。

---

## 58. BatchNorm 还有一个麻烦：训练和推理行为不同

BatchNorm 在训练阶段：

```text
当前Batch
   ↓
计算均值
   ↓
计算方差
```

比如：

$$
\mu_B
$$

以及：

$$
\sigma_B^2
$$

---

但是推理的时候可能只有：

```text
1个样本
```

例如：

```text
Batch Size = 1
```

这时候当前 Batch 的统计量就不可靠。

所以 BatchNorm 在训练过程中会额外维护：

```text
running_mean
running_var
```

即：

> 均值和方差的滑动平均。

---

## 59. BatchNorm 的 Running Mean

例如：

$$
running\_mean
\leftarrow
(1-m)
running\_mean
+
m\mu_B
$$

类似地：

$$
running\_var
\leftarrow
(1-m)
running\_var
+
m\sigma_B^2
$$

---

训练的时候：

```text
使用当前Batch统计量
```

推理的时候：

```text
使用running_mean
使用running_var
```

因此：

$$
\boxed{
BatchNorm训练和推理行为不同
}
$$

---

## 60. 为什么 model.train() 和 model.eval() 很重要？

PyTorch 中：

```python
model.train()
```

表示训练模式。

BatchNorm 使用：

```text
当前Batch均值
当前Batch方差
```

并更新：

```text
running_mean
running_var
```

---

而：

```python
model.eval()
```

表示推理模式。

BatchNorm 使用：

```text
running_mean
running_var
```

不再使用当前 Batch 的统计量。

因此：

```text
model.train()
```

和：

```text
model.eval()
```

对 BatchNorm 是有实际影响的。

---

## 61. RMSNorm 不需要 Running Mean

RMSNorm 每次都只需要：

$$
x
$$

本身。

例如：

```text
训练：
当前Token自己计算RMS
```

推理：

```text
当前Token还是自己计算RMS
```

因此 RMSNorm 不需要：

```text
running_mean
running_var
```

训练和推理的计算方式基本一样。

---

## 62. Batch Size 对 BatchNorm 的影响

因为 BatchNorm 依赖：

$$
\mu_B
$$

和：

$$
\sigma_B^2
$$

因此：

```text
Batch Size越大
↓
统计量通常越稳定
```

而：

```text
Batch Size特别小
↓
均值和方差估计容易不稳定
```

例如：

```text
Batch Size = 1
```

BatchNorm 可能就会产生明显问题。

---

而 RMSNorm：

```text
Batch Size = 1

Batch Size = 8

Batch Size = 128
```

基本都没有这个问题。

因为每个样本自己算。

---

## 63. BatchNorm、LayerNorm、RMSNorm 放在一起看

这是理解这三个 Normalization 最推荐的方法。

假设：

$$
X=
\begin{bmatrix}
1&2&3\\
4&5&6\\
7&8&9
\end{bmatrix}
$$

---

### 63.1 BatchNorm

跨样本：

```text
↓     ↓     ↓

1     2     3
4     5     6
7     8     9
```

即：

> 同一个 Feature，不同样本一起归一化。

---

### 63.2 LayerNorm

每个样本自己：

```text
1  2  3  →

4  5  6  →

7  8  9  →
```

但 LayerNorm 会：

#### 63.2.1 第一步

减均值：

$$
x-\mu
$$

#### 63.2.2 第二步

除标准差：

$$
\frac{x-\mu}
{\sqrt{\sigma^2+\epsilon}}
$$

---

### 63.3 RMSNorm

同样是：

```text
1  2  3  →

4  5  6  →

7  8  9  →
```

但 RMSNorm 不减均值。

只计算：

$$
\frac{x}
{\sqrt{mean(x^2)+\epsilon}}
$$

---

## 64. LayerNorm 和 RMSNorm 的关系

LayerNorm：

$$
\boxed{
LayerNorm(x)
=
\gamma
\frac{x-\mu}
{\sqrt{\sigma^2+\epsilon}}
+\beta
}
$$

而 RMSNorm：

$$
\boxed{
RMSNorm(x)
=
\gamma
\frac{x}
{\sqrt{mean(x^2)+\epsilon}}
}
$$

因此可以粗略理解：

```text
LayerNorm
   ↓
去掉中心化过程
   ↓
RMSNorm
```

也就是说：

$$
\boxed{
RMSNorm更像是LayerNorm的简化版
}
$$

而不是：

$$
RMSNorm
$$

是 BatchNorm 的简化版。

---

## 65. 三种 Norm 最重要的区别

| 特征              | BatchNorm | LayerNorm | RMSNorm |
| --------------- | --------- | --------- | ------- |
| 统计范围            | 多个样本之间    | 单个样本内部    | 单个样本内部  |
| 跨 Batch         | 是         | 否         | 否       |
| 减均值             | 是         | 是         | 否       |
| 除标准差            | 是         | 是         | 否       |
| 除 RMS           | 否         | 否         | 是       |
| \(\gamma\)      | 有         | 有         | 有       |
| \(\beta\)       | 通常有       | 有         | 通常没有    |
| 依赖 Batch Size   | 强         | 否         | 否       |
| Running Mean    | 有         | 无         | 无       |
| Running Var     | 有         | 无         | 无       |
| Train / Eval 不同 | 是         | 基本相同      | 基本相同    |
| CNN             | 常见        | 较少        | 较少      |
| Transformer     | 少见        | 常见        | 非常常见    |
| LLM             | 少见        | 常见        | 非常常见    |

---

## 66. 最容易记忆的方法

可以把三种方法理解成：

```text
Normalization
       │
       ├──────────────────────┐
       │                      │
    看别人                  看自己
       │                      │
  BatchNorm          ┌────────┴────────┐
                     │                 │
                LayerNorm          RMSNorm
                     │                 │
               减均值+除方差       只控制RMS
```

---

## 67. 一句话理解 BatchNorm

> **BatchNorm：看看同一个 Batch 里，别人这个特征是什么水平，然后把自己调整到统一尺度。**

---

## 68. 一句话理解 LayerNorm

> **LayerNorm：不管别人，只看自己这一整组特征，把自己的均值和方差标准化。**

---

## 69. 一句话理解 RMSNorm

> **RMSNorm：也不管别人，只看自己的数值大小，而且连均值都不减，只控制整体尺度。**

---

## 70. 对 Transformer 最重要的理解

Transformer 中通常有：

$$
X
\in
\mathbb{R}^{B\times T\times D}
$$

对于一个 Token：

$$
x_{b,t}
\in
\mathbb{R}^{D}
$$

RMSNorm 做的是：

$$
\boxed{
对这个Token自己的D维Hidden State做归一化
}
$$

而不是：

$$
\boxed{
对整个Batch做归一化
}
$$

所以：

```text
Token
 ↓
D维Hidden State
 ↓
RMSNorm
 ↓
控制这个Token自身的数值尺度
```

这就是 RMSNorm 特别适合 Transformer / LLM 的核心原因之一。

## 71. 最终总结

### 71.1 BatchNorm

核心：

$$
\boxed{
跨样本统计
}
$$

计算：

$$
\mu_B
$$

和：

$$
\sigma_B^2
$$

然后：

$$
\frac{x-\mu_B}
{\sqrt{\sigma_B^2+\epsilon}}
$$

特点：

```text
依赖Batch
训练和推理不同
需要running_mean / running_var
CNN中非常常见
```

---

### 71.2 RMSNorm

核心：

$$
\boxed{
每个样本 / Token 自己统计
}
$$

计算：

$$
RMS(x)
=
\sqrt{mean(x^2)+\epsilon}
$$

然后：

$$
\frac{x}{RMS(x)}
$$

特点：

```text
不跨样本
不减均值
不依赖Batch Size
不需要Running Mean / Var
非常适合Transformer / LLM
```

---

最核心的一句话：

$$
\boxed{
BatchNorm看Batch中的“别人”，
RMSNorm只看“自己”。
}
$$

而 RMSNorm 与 LayerNorm 的关系更近：

$$
\boxed{
RMSNorm
\approx
LayerNorm
-
均值中心化
}
$$
