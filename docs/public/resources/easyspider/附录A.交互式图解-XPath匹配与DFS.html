3自动匹配 vs 手动匹配

两条互补的路径：自动负责快，手动负责准。

维度自动（findRelated）手动（relatedTest）
输入1 个元素≥2 个元素
方法逐层去索引试探找各层"全一致"的索引
返回码直接进 readyList50（同类）/ 100（不同类）
产出待选集合最简 XPath（相对）
用途快速猜测同类校正遗漏、处理复杂结构

手动匹配：逐层索引比较

A: /html/body/div/div[2]/ul/li[1]/a[1]
B: /html/body/div/div[2]/ul/li[2]/a[1]
C: /html/body/div/div[2]/ul/li[3]/a[1]
→ div[2] 三层全同，保留 2
→ li 三层不同，置 -1（去掉）
→ 最终：/html/body/div/div[2]/ul/li/a[1]

4算法要点速查

  1. 拆 XPath 成「标签序列 + 索引序列」，如 ["html","body","div"] 与 [-1,-1,2]。
  2. 自动匹配：从右往左，每次把一层的索引置 -1，重新 evaluate。
  3. 用两次 iterateNext() 判断匹配是否 ≥2。
  4. 手动匹配：标签序列不一致 → 返回 100；否则逐层比索引，全同保留、有异置 -1。
  5. DFS 用栈：pop() 出栈，子节点逆序压栈。
  6. BFS 用队列：shift() 出队，子节点正序入队。
  7. 求共有子元素用 Set 求交，复杂度 O(m×n)。
