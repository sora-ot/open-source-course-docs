## 一条推荐的阅读路线

### 1. 先看输入与输出

不急着记住每个函数。先回答：用户给了什么，程序最后产生什么，中间经过哪些模块？在项目导读中建立这张地图。

### 2. 跟踪一条完整流程

EasySpider 可以跟着“选一个网页元素”走；OpenClaw 可以跟着“一条用户消息”走；两个十分钟项目则各用一条训练或调用流水线串起来。

### 3. 把原理与代码放在一起

记录当前对象、输入、输出和状态变化。点击讲义中的本地源码引用，可以打开带行号的源码阅读页，再沿浏览器返回继续阅读。

### 4. 用一个小例子确认理解

打开 [交互图解与演示](/labs/)，观察 XPath、遍历与流程图的数据结构；LangChain 讲义还包含无需 API Key 的模拟例子，适合在本机验证组件组合。

## 使用文档网站

- 顶部“项目讲义”可以切换五个项目。MiniMind 按知识主题组织原理、代码与例子，每篇使用概括性标题和独立的小节编号。
- 左侧是项目章节，右侧是本页目录；手机端从“章节目录”打开侧栏。
- 使用顶部搜索，或按 Ctrl / Command + K 搜索概念与代码名称。
- 代码块可以复制，横向滚动查看较长代码；公式与流程图会在正文中展示。
- 页面底部可下载 Markdown，便于离线阅读；MiniMind 提供清理后的完整讲义。

## 学习与实践的边界

网页负责展示讲义、静态源码和现成的交互图解。讲义中的训练、爬虫、浏览器扩展和模型调用代码，需要按对应章节在本地环境运行。视频和纯前端图解可以直接在网站打开。
